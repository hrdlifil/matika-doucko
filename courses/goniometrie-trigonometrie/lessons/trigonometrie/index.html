Kapitola 6 · Část 1

Sinová věta

Sinová věta vyjadřuje vztah mezi stranami trojúhelníku a siny protilehlých úhlů. Je jedním z nejdůležitějších nástrojů pro řešení obecných trojúhelníků.

📐 Sinová věta

V každém trojúhelníku ABC s protilehlými stranami a, b, c platí:

Sinová věta a / sin α = b / sin β = c / sin γ = 2R R = poloměr opsané kružnice

Ekvivalentně: sin α / a = sin β / b = sin γ / c

📊 Trojúhelník a sinová věta

Trojúhelník ABC s vyznačenými stranami, úhly a opsanou kružnicí o poloměru R.

🔍

Důkaz sinové věty

Výška z vrcholu C
Označme vc výšku na stranu c.
Z pravého trojúhelníku: vc = a · sin β = b · sin α
Úprava
a · sin β = b · sin α → a / sin α = b / sin β
Analogicky pro výšku va: b / sin β = c / sin γ
Vztah s opsanou kružnicí
Pomocí obvodového úhlu nad průměrem 2R: a / sin α = 2R
💡

Kdy použít sinovou větu?

1. Známe dva úhly a jednu stranu (úloha AUA nebo UAU).
2. Známe dvě strany a úhel proti jedné z nich (úloha SSU — pozor na nejednoznačnost!).
3. Potřebujeme spočítat poloměr opsané kružnice.

Využití sinové věty

Sinová věta slouží k řešení trojúhelníků, kde známe úhly a některé strany. Ukážeme si typické příklady a upozorníme na nejednoznačné případy.

📝 Příklad 1: V trojúhelníku ABC je α = 40°, β = 75° a a = 10 cm. Najděte b a c.

Krok 1: Třetí úhel
γ = 180° − 40° − 75° = 65°
Krok 2: Sinová věta pro b
a / sin α = b / sin β
b = a · sin β / sin α = 10 · sin 75° / sin 40° ≈ 10 · 0,9659 / 0,6428 ≈ 15,03 cm
Krok 3: Sinová věta pro c
c = a · sin γ / sin α = 10 · sin 65° / sin 40° ≈ 10 · 0,9063 / 0,6428 ≈ 14,10 cm
✅ Řešení
b ≈ 15,03 cm,   c ≈ 14,10 cm,   γ = 65°

📝 Příklad 2: Nejednoznačný případ (SSU) — a = 8, b = 5, α = 30°. Kolik existuje trojúhelníků?

Krok 1: Sinová věta pro β
sin β = b · sin α / a = 5 · sin 30° / 8 = 5 · 0,5 / 8 = 0,3125
Krok 2: Ověření podmínek
sin β = 0,3125 < 1 ✅ → β ≈ 18,21°
Druhá možnost: β' = 180° − 18,21° = 161,79°
α + β' = 30° + 161,79° = 191,79° > 180° ❌ → jen jeden trojúhelník
✅ Řešení
Existuje právě 1 trojúhelník s β ≈ 18,21°, γ ≈ 131,79°

📝 Příklad 3: Poloměr opsané kružnice — trojúhelník s a = 6, α = 45°.

Krok 1: Vzorec
2R = a / sin α
✅ Řešení
R = a / (2 · sin α) = 6 / (2 · sin 45°) = 6 / (2 · √2/2) = 6 / √2 = 3√2 ≈ 4,24
⚠️

Nejednoznačnost (SSU případ)

Když známe 2 strany a úhel proti kratší straně, mohou nastat 3 situace:
0 řešení (sin β > 1), 1 řešení (β = 90° nebo β' dá součet > 180°), 2 řešení (obě β platné).

Kosinová věta

Kosinová věta zobecňuje Pythagorovu větu pro obecné trojúhelníky. Umožňuje vypočítat stranu z ostatních dvou stran a sevřeného úhlu, nebo naopak úhel ze tří stran.

📐 Kosinová věta

V trojúhelníku ABC platí:

pro stranu c c² = a² + b² − 2ab · cos γ
pro stranu a a² = b² + c² − 2bc · cos α
pro stranu b b² = a² + c² − 2ac · cos β

Pro γ = 90° se redukuje na Pythagorovu větu: c² = a² + b²

📊 Kosinová věta — geometrická interpretace

Trojúhelník se stranami a, b, c a vyznačeným úhlem γ. Zobrazena je i "korekce" oproti Pythagorovci.

🔍

Odvození kosinové věty

Souřadnicový přístup
Umístíme trojúhelník: C = [0,0], B = [a, 0], A = [b cos γ, b sin γ]
Vzdálenost AB
c² = |AB|² = (a − b cos γ)² + (b sin γ)²
= a² − 2ab cos γ + b² cos²γ + b² sin²γ
= a² − 2ab cos γ + b²(cos²γ + sin²γ)
= a² + b² − 2ab cos γ

📐 Inverzní tvar — výpočet úhlu

cos γ = (a² + b² − c²) / (2ab) γ = arccos(...)
💡

Kdy použít kosinovou větu?

1. Známe dvě strany a sevřený úhel (SUS) → spočítáme třetí stranu.
2. Známe tři strany (SSS) → spočítáme úhly.

Kapitola 6 · Část 4

Využití kosinové věty

Kosinovou větu využíváme ke dvěma hlavním typům úloh: výpočtu třetí strany ze dvou stran a sevřeného úhlu, a výpočtu úhlů ze tří daných stran.

📝 Příklad 1: (SUS) — V trojúhelníku ABC je a = 7, b = 5, γ = 60°. Najděte c.

Krok 1: Kosinová věta
c² = a² + b² − 2ab cos γ = 49 + 25 − 2·7·5·cos 60°
= 74 − 70 · 0,5 = 74 − 35 = 39
✅ Řešení
c = √39 ≈ 6,24

📝 Příklad 2: (SSS) — Trojúhelník má strany a = 8, b = 6, c = 10. Najděte všechny úhly.

Krok 1: Úhel γ (proti nejdelší straně)
cos γ = (a² + b² − c²) / (2ab) = (64 + 36 − 100) / (2·8·6) = 0 / 96 = 0
γ = 90° (pravoúhlý trojúhelník!)
Krok 2: Úhel α
cos α = (b² + c² − a²) / (2bc) = (36 + 100 − 64) / (2·6·10) = 72/120 = 0,6
α ≈ 53,13°
✅ Řešení
α ≈ 53,13°,   β ≈ 36,87°,   γ = 90°

📝 Příklad 3: Kombinace — a = 12, b = 9, γ = 120°. Najděte c a zbylé úhly.

Krok 1: Kosinová věta pro c
c² = 144 + 81 − 2·12·9·cos 120° = 225 − 216·(−0,5) = 225 + 108 = 333
c = √333 ≈ 18,25
Krok 2: Sinová věta pro α
sin α / a = sin γ / c → sin α = 12 · sin 120° / 18,25 ≈ 12 · 0,866 / 18,25 ≈ 0,5695
α ≈ 34,72°
✅ Řešení
c ≈ 18,25,   α ≈ 34,72°,   β ≈ 25,28°

Další trigonometrické věty

Kromě sinové a kosinové věty existují další užitečné vztahy: vzorce pro obsah trojúhelníku, tangentová věta, Heronův vzorec a poloměry vepsané a opsané kružnice.

📐 Obsah trojúhelníku pomocí sinu

S = ½ · a · b · sin γ libovolné dvě strany a sevřený úhel
S = ½ · a · c · sin β
S = ½ · b · c · sin α

📐 Heronův vzorec

Obsah trojúhelníku pouze ze tří stran:

s = (a+b+c)/2 S = √(s(s−a)(s−b)(s−c)) s = polovina obvodu

📐 Poloměr vepsané kružnice

r = S / s S = obsah, s = polovina obvodu

📐 Tangentová věta

tg((α−β)/2) = (a−b)/(a+b) · cotg(γ/2)

Alternativně: (a−b) / (a+b) = tg((α−β)/2) / tg((α+β)/2)

📝 Příklad 1: Obsah — trojúhelník se stranami a = 5, b = 7, γ = 30°

Vzorec
S = ½ · 5 · 7 · sin 30° = ½ · 35 · 0,5 = 8,75
✅ Řešení
S = 8,75 cm²

📝 Příklad 2: Heronův vzorec — trojúhelník 3, 4, 5

Krok 1: Polovina obvodu
s = (3 + 4 + 5) / 2 = 6
Krok 2: Dosadíme
S = √(6 · 3 · 2 · 1) = √36 = 6
✅ Řešení
S = 6 cm²   (ověření: ½ · 3 · 4 = 6 ✅)

📝 Příklad 3: Poloměr vepsané kružnice — trojúhelník 5, 12, 13

Krok 1: Obsah (pravoúhlý trojúhelník)
S = ½ · 5 · 12 = 30
Krok 2: Polovina obvodu
s = (5 + 12 + 13) / 2 = 15
✅ Řešení
r = S / s = 30 / 15 = 2

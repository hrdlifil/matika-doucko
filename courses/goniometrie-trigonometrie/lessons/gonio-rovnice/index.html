Základní goniometrické rovnice

Základní goniometrické rovnice mají tvar sin x = a, cos x = a nebo tg x = a. Klíčem k jejich řešení je pochopení, kde na jednotkové kružnici se hledané hodnoty nacházejí.

📐 Rovnice sin x = a

Pro |a| ≤ 1 má řešení:

x₁ = arcsin a + 2kπ k ∈ ℤ
x₂ = π − arcsin a + 2kπ k ∈ ℤ

Pro |a| > 1 rovnice nemá řešení (sin x nabývá hodnot z [−1, 1]).

📐 Rovnice cos x = a

Pro |a| ≤ 1 má řešení:

x = ±arccos a + 2kπ k ∈ ℤ

📐 Rovnice tg x = a

Pro libovolné a ∈ ℝ má řešení:

x = arctg a + kπ k ∈ ℤ (perioda tg je π)

📊 Grafické řešení rovnice sin x = ½

Na obrázku jsou vyznačena řešení rovnice sin x = ½ na jednotkové kružnici i na grafu funkce sinus.

📝 Příklad: Řešte sin x = ½

Krok 1: Najdi základní úhel
arcsin(½) = π/6 (30°)
Krok 2: Urči všechna řešení
x₁ = π/6 + 2kπ   nebo   x₂ = π − π/6 + 2kπ = 5π/6 + 2kπ
✅ Řešení
x = π/6 + 2kπ   nebo   x = 5π/6 + 2kπ,   k ∈ ℤ

📝 Příklad: Řešte cos x = −√2/2

Krok 1: Najdi základní úhel
arccos(√2/2) = π/4, protože cos je záporný → úhly ve 2. a 3. kvadrantu
Krok 2: Urči řešení
x = ±(π − π/4) + 2kπ = ±3π/4 + 2kπ
✅ Řešení
x = ±3π/4 + 2kπ,   k ∈ ℤ

📝 Příklad: Řešte tg x = 1

Krok 1: Najdi základní úhel
arctg(1) = π/4 (45°)
✅ Řešení
x = π/4 + kπ,   k ∈ ℤ

Základní substituce

Mnohé goniometrické rovnice lze převést na algebraické rovnice vhodnou substitucí. Nejčastější substituce je t = sin x nebo t = cos x, čímž rovnici převedeme na rovnici s neznámou t.

📐 Postup řešení substitucí

1. Zvolíme substituci
Např. t = sin x, kde t ∈ [−1, 1]
2. Vyřešíme rovnici pro t
Dostaneme algebraickou rovnici (lineární, kvadratickou...)
3. Ověříme podmínky
Platí t ∈ [−1, 1]? (pokud t = sin x nebo cos x)
4. Zpětná substituce
Z hodnot t určíme x pomocí arcsin, arccos, arctg

📝 Příklad: Řešte 2sin²x − sin x − 1 = 0

Krok 1: Substituce
Položíme t = sin x, t ∈ [−1, 1]
Rovnice: 2t² − t − 1 = 0
Krok 2: Řešení kvadratické rovnice
D = 1 + 8 = 9, √D = 3
t₁ = (1 + 3) / 4 = 1
t₂ = (1 − 3) / 4 = −½
Krok 3: Ověření podmínek
t₁ = 1 ∈ [−1, 1] ✅    t₂ = −½ ∈ [−1, 1] ✅
Krok 4: Zpětná substituce
sin x = 1 → x = π/2 + 2kπ
sin x = −½ → x = −π/6 + 2kπ nebo x = π + π/6 + 2kπ = 7π/6 + 2kπ
✅ Řešení
x = π/2 + 2kπ,   x = −π/6 + 2kπ,   x = 7π/6 + 2kπ,   k ∈ ℤ

📊 Graf rovnice 2sin²x − sin x − 1 = 0

Graf funkce f(x) = 2sin²x − sin x − 1. Body průniku s osou x jsou řešení rovnice.

📝 Příklad: Řešte 2cos²x + 3cos x + 1 = 0

Krok 1: Substituce
t = cos x, t ∈ [−1, 1] → 2t² + 3t + 1 = 0
Krok 2: Řešení
(2t + 1)(t + 1) = 0
t₁ = −½,   t₂ = −1
Krok 3: Zpětná substituce
cos x = −½ → x = ±2π/3 + 2kπ
cos x = −1 → x = π + 2kπ
✅ Řešení
x = ±2π/3 + 2kπ,   x = π + 2kπ,   k ∈ ℤ
💡

Kdy použít substituci t = sin x / cos x?

Substituci používáme, když se v rovnici vyskytuje pouze jedna goniometrická funkce (nebo lze vše převést na jednu pomocí identity sin²x + cos²x = 1).

Složitější substituce

Některé rovnice vyžadují pokročilejší substituční techniky. Nejdůležitější je univerzální substituce t = tg(x/2), která převede libovolnou goniometrickou rovnici na algebraickou.

📐 Univerzální substituce: t = tg(x/2)

Vyjádření goniometrických funkcí pomocí t = tg(x/2):

sin x = 2t / (1 + t²)
cos x = (1 − t²) / (1 + t²)
tg x = 2t / (1 − t²)

⚠️ Substituce platí jen pro x ≠ π + 2kπ (kde tg(x/2) není definován).

🔍

Odvození: proč t = tg(x/2) funguje?

Pomocí vzorců pro dvojnásobný úhel (x = 2·(x/2)):

sin x = 2 sin(x/2) cos(x/2)
Dělíme čitatele i jmenovatele cos²(x/2):
= 2·tg(x/2) / (1 + tg²(x/2)) = 2t / (1 + t²)
cos x = cos²(x/2) − sin²(x/2)
Dělíme cos²(x/2):
= (1 − tg²(x/2)) / (1 + tg²(x/2)) = (1 − t²) / (1 + t²)

📝 Příklad: Řešte 3sin x + 4cos x = 5

Krok 1: Univerzální substituce t = tg(x/2)
sin x = 2t/(1+t²),   cos x = (1−t²)/(1+t²)
3·2t/(1+t²) + 4·(1−t²)/(1+t²) = 5
Krok 2: Vynásobíme (1 + t²)
6t + 4 − 4t² = 5 + 5t²
9t² − 6t + 1 = 0
(3t − 1)² = 0
Krok 3: Řešení
t = 1/3, tedy tg(x/2) = 1/3
✅ Řešení
x = 2·arctg(1/3) + 2kπ,   k ∈ ℤ

📐 Substituce typu a·sin x + b·cos x = c

Alternativní postup — převedeme na „amplitudový" tvar:

a·sin x + b·cos x = √(a²+b²) · sin(x + φ) kde tg φ = b/a

Rovnice má řešení ⟺ |c| ≤ √(a² + b²)

📝 Příklad: Řešte sin x + cos x = 1 (amplitudový tvar)

Krok 1: Převod na amplitudový tvar
a = 1, b = 1 → √(a²+b²) = √2,   tg φ = 1 → φ = π/4
sin x + cos x = √2 · sin(x + π/4)
Krok 2: Rovnice
√2 · sin(x + π/4) = 1 → sin(x + π/4) = 1/√2 = √2/2
✅ Řešení
x + π/4 = π/4 + 2kπ → x = 2kπ
x + π/4 = 3π/4 + 2kπ → x = π/2 + 2kπ

Těžší goniometrické rovnice

Složitější rovnice vyžadují kombinaci několika technik — rozkladu na součin, substitucí, použití vzorců pro dvojnásobný úhel a dalších úprav.

📐 Důležité strategie

Rozklad na součin
Převedeme rovnici na tvar A · B = 0, poté řešíme A = 0 nebo B = 0
Využití identity sin²x + cos²x = 1
Převedeme rovnici na jednu proměnnou (t = sin x nebo t = cos x)
Vzorce pro dvojnásobný úhel
sin 2x = 2sin x cos x, cos 2x = 1 − 2sin²x atd.
Převod na stejný argument
Pokud se v rovnici vyskytuje sin x i sin 2x, převedeme vše na x nebo 2x

📝 Příklad: Řešte sin 2x = cos x

Krok 1: Použijeme vzorec pro sin 2x
2 sin x cos x = cos x
Krok 2: Převedeme na jednu stranu
2 sin x cos x − cos x = 0 → cos x · (2 sin x − 1) = 0
Krok 3: Řešíme dva případy
cos x = 0 → x = π/2 + kπ
sin x = ½ → x = π/6 + 2kπ nebo x = 5π/6 + 2kπ
✅ Řešení
x = π/2 + kπ,   x = π/6 + 2kπ,   x = 5π/6 + 2kπ,   k ∈ ℤ

📊 Graf rovnice sin 2x = cos x

Grafy sin 2x (oranžová) a cos x (modrá). Body průniku jsou řešení rovnice.

📝 Příklad: Řešte sin²x − cos²x = sin x

Krok 1: Využijeme cos 2x = cos²x − sin²x
sin²x − cos²x = −cos 2x, tedy: −cos 2x = sin x
Krok 2: Použijeme cos 2x = 1 − 2sin²x
−(1 − 2sin²x) = sin x
2sin²x − 1 = sin x → 2sin²x − sin x − 1 = 0
Krok 3: Substituce t = sin x
2t² − t − 1 = 0 → (2t + 1)(t − 1) = 0
t₁ = −½,   t₂ = 1
✅ Řešení
x = π/2 + 2kπ,   x = 7π/6 + 2kπ,   x = 11π/6 + 2kπ,   k ∈ ℤ

📝 Příklad: Řešte sin x · cos x = ¼

Krok 1: Využijeme sin 2x = 2sin x cos x
sin x cos x = sin(2x)/2, tedy: sin(2x)/2 = ¼ → sin(2x) = ½
Krok 2: Řešíme základní rovnici
2x = π/6 + 2kπ nebo 2x = 5π/6 + 2kπ
✅ Řešení
x = π/12 + kπ   nebo   x = 5π/12 + kπ,   k ∈ ℤ

Úpravy goniometrických výrazů

Zjednodušování a dokazování goniometrických identit je klíčová dovednost. Používáme základní identity, součtové vzorce a různé algebraické úpravy.

📐 Základní identity pro úpravy

sin²x + cos²x = 1
1 + tg²x = 1/cos²x
1 + cotg²x = 1/sin²x
tg x · cotg x = 1

📝 Příklad: Zjednodušte (1 − sin²x) / cos x

Krok 1: Využijeme identitu
1 − sin²x = cos²x
✅ Výsledek
cos²x / cos x = cos x

📝 Příklad: Dokažte, že (sin x + cos x)² = 1 + sin 2x

Levá strana — rozepíšeme binomický vzorec
(sin x + cos x)² = sin²x + 2 sin x cos x + cos²x
Využijeme identity
= (sin²x + cos²x) + 2 sin x cos x
= 1 + sin 2x
✅ L = P   □
Levá strana = pravá strana. Identita je dokázána.

📝 Příklad: Zjednodušte tg x + cotg x

Krok 1: Přepíšeme na sin a cos
tg x + cotg x = sin x / cos x + cos x / sin x
Krok 2: Společný jmenovatel
= (sin²x + cos²x) / (sin x · cos x) = 1 / (sin x · cos x)
Krok 3: Využijeme sin 2x = 2sin x cos x
sin x · cos x = sin(2x)/2
✅ Výsledek
tg x + cotg x = 2 / sin 2x

📝 Příklad: Zjednodušte (1 − cos 2x) / sin 2x

Krok 1: Rozepíšeme vzorci
1 − cos 2x = 2sin²x (ze vzorce cos 2x = 1 − 2sin²x)
sin 2x = 2 sin x cos x
✅ Výsledek
2sin²x / (2 sin x cos x) = sin x / cos x = tg x
💡

Tipy pro úpravy výrazů

1. Převeďte vše na sin a cos, pokud si nevíte rady.
2. Hledejte vzorec sin²x + cos²x = 1.
3. Využívejte vzorce pro dvojnásobný úhel.
4. Při důkazu identity upravujte jednu stranu na tvar druhé.
5. Společný jmenovatel je váš přítel.

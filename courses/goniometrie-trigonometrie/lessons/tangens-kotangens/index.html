Sekce 1

Tangens a kotangens jako funkce

Už víme, co je sinus a kosinus. Teď přidáme další dvě goniometrické funkce — tangens a kotangens. Jsou definovány jako podíly sinu a kosinu a mají unikátní vlastnosti — zejména nemají obor hodnot omezený na [−1, 1].

📐 Definice

Funkce tangens a kotangens jsou definovány:

  • tg x = sin x / cos x — definováno pro všechna x, kde cos x ≠ 0
  • cotg x = cos x / sin x — definováno pro všechna x, kde sin x ≠ 0

Definiční obor tg: D(tg) = ℝ ∖ {π/2 + kπ, k ∈ ℤ}
Definiční obor cotg: D(cotg) = ℝ ∖ {kπ, k ∈ ℤ}
Obor hodnot: H(tg) = H(cotg) = ℝ (celá reálná osa!)

💡

Geometrický význam tangentu

Na jednotkové kružnici je tangens úhlu x roven délce úsečky od průsečíku přímky (procházející počátkem pod úhlem x) s tečnou kružnice v bodě (1, 0). Proto se jmenuje „tangens" — z latinského tangere = dotýkat se.

🔄 Tangens na jednotkové kružnici

Táhněte posuvníkem a sledujte, jak se mění tangens a kotangens úhlu. Tangens je znázorněn na svislé tečně (oranžově), kotangens na vodorovné tečně (zeleně).

tg x = 1.000
cotg x = 1.000
sin x = 0.707
cos x = 0.707

Klíčové vlastnosti

Perioda tg(x + π) = tg x Perioda je π (ne 2π!)
Parita tg(−x) = −tg x Obě funkce jsou liché
Vzájemný vztah tg x · cotg x = 1 Jsou navzájem převrácené
Asymptoty tg x = π/2 + kπ Tam je cos x = 0

Sekce 2

Graf funkce tangens a kotangens

Grafy tangentu a kotangentu vypadají úplně jinak než sinusovka a kosinusovka. Mají svislé asymptoty — body, kde funkce „utíká" do nekonečna. Perioda je pouze π (namísto 2π).

📊 Tangentovka a kotangentovka

  • tg x roste na každém intervalu (kπ − π/2, kπ + π/2) od −∞ do +∞
  • cotg x klesá na každém intervalu (kπ, (k+1)π) od +∞ do −∞
  • Nulové body tg x: x = kπ (k ∈ ℤ)
  • Nulové body cotg x: x = π/2 + kπ (k ∈ ℤ)

📈 Interaktivní graf

Prozkoumejte grafy tangentu a kotangentu. Posuvníkem vyberte bod na grafu a sledujte jeho hodnotu.

tg x = 0.000
cotg x = —
🔍

Proč tangens „utíká" do nekonečna?

Protože tg x = sin x / cos x. Když se cos x blíží k nule (u π/2), dělíme číslem blízkým nule — výsledek rapidně roste. V bodě π/2 je cos x = 0, takže tangens není definován a graf má svislou asymptotu.

Trik pro zapamatování tg a cotg

Stačí si pamatovat sin a cos! Tangens je vždy sin/cos a kotangens je cos/sin. Navíc si všimněte symetrie: hodnoty cotg jsou hodnoty tg v opačném pořadí.

Sekce 5

Praktické odvození všech hodnot

Nemusíte si hodnoty tupě pamatovat — můžete je odvodit pomocí dvou speciálních trojúhelníků. Projděte si krok za krokem, jak na to.

📐 Dva klíčové trojúhelníky

  • Trojúhelník 45-45-90: Rovnoramenný pravoúhlý trojúhelník s odvěsnami délky 1. Přepona = √2. Dává nám hodnoty pro 45°.
  • Trojúhelník 30-60-90: Polovina rovnostranného trojúhelníku. Strany v poměru 1 : √3 : 2. Dává nám hodnoty pro 30° a 60°.

Sekce 6

Odvození hodnot pro tangens a kotangens

Hodnoty tangentu a kotangentu se snadno spočítají ze sinu a kosinu. Sledujte animovaný výpočet pro každý standardní úhel.

🔑 Klíčové vzorce

  • tg x = sin x / cos x
  • cotg x = cos x / sin x = 1 / tg x

Stačí tedy znát sin a cos — tangens a kotangens z nich vždy dopočítáte!

🧮 Krok za krokem

Vyberte úhel a sledujte, jak se z sin a cos vypočítá tg a cotg:

Vyberte úhel výše

⚠️

Pozor na dělení nulou!

Pro 0° je sin 0° = 0, tedy cotg 0° = cos 0° / sin 0° = 1/0 — není definován. Podobně pro 90° je cos 90° = 0, tedy tg 90° = sin 90° / cos 90° = 1/0 — není definován. Tyto body odpovídají asymptotám na grafech.

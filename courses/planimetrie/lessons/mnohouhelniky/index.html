Téma 1

Mnohoúhelníky (n-úhelníky)

n-úhelník je rovinný útvar o n vrcholech a n stranách, kde n ≥ 3. Pro konvexní n-úhelník platí důležité vztahy pro počet úhlopříček a součet vnitřních úhlů.

Klíčové vzorce

  • Počet úhlopříček: d = n(n - 3) / 2
  • Součet vnitřních úhlů: S = (n - 2) · 180°
  • Triangulace z jednoho vrcholu: vždy n - 2 trojúhelníků

🎮 Anatomie n-úhelníku

Měňte počet stran a zapněte úhlopříčky nebo triangulaci. Hodnoty se počítají automaticky.

n-úhelník je konvexní, vrcholy jsou značeny A, B, C, ...

Brilliant tip

Vzorec pro součet úhlů není potřeba memorovat bez kontextu. Stačí si představit rozřezání n-úhelníku na n - 2 trojúhelníků.

Téma 2

Pravidelný n-úhelník

Pravidelný n-úhelník má všechny strany stejně dlouhé a všechny vnitřní úhly shodné. Lze ho zapsat přes kružnici opsanou s poloměrem R a středový úhel.

Vztahy pro pravidelný n-úhelník

  • Středový úhel: φ = 360° / n
  • Vnitřní úhel: α = (n - 2) · 180° / n
  • Délka strany: a = 2R · sin(π / n)
  • Apotéma: r = R · cos(π / n)

Upravujte n, poloměr R a natočení. Sledujte, jak se mění délka strany a úhly.

Téma 3

Čtyřúhelníky

Čtyřúhelníky lze třídit podle rovnoběžnosti, shodnosti stran, pravých úhlů nebo diagonál. V tomto panelu porovnáte vlastnosti jednotlivých typů.

Přehled typů

  • Lichoběžník: právě jedna dvojice protějších stran je rovnoběžná
  • Rovnoběžník: obě dvojice protějších stran jsou rovnoběžné
  • Obdélník: rovnoběžník se čtyřmi pravými úhly
  • Kosočtverec: rovnoběžník se všemi stranami shodnými
  • Čtverec: obdélník i kosočtverec současně

🎮 Klasifikace čtyřúhelníků

Vyberte typ a měňte parametry. Systém průběžně kontroluje hlavní vlastnosti útvaru.

Téma 4

Tečnový a tětivový čtyřúhelník

Tětivový (cyklický) čtyřúhelník má všechny vrcholy na jedné kružnici. Tečnový čtyřúhelník má všechny strany tečné k jedné kružnici. Každý typ má charakteristickou rovnost.

Rozhodující vlastnosti

  • Tětivový: ∠A + ∠C = 180° a ∠B + ∠D = 180°
  • Tečnový: pro strany v pořadí platí a + c = b + d

🎮 Dvě speciální konstrukce vedle sebe

Vlevo měníte tětivový čtyřúhelník na kružnici, vpravo tečnový čtyřúhelník k vepsané kružnici.

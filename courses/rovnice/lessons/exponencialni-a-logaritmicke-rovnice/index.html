Téma 1

Exponenciální rovnice

Exponenciální rovnice obsahují neznámou v exponentu, například 2x+1 = 7. Základ exponenciální funkce musí splňovat a > 0, a ≠ 1. Typická výhoda: funkce ax je prostá, takže po převedení na stejný základ můžeme porovnat exponenty.

i

Nejdůležitější princip

Pro a > 0, a ≠ 1 platí: au = av ⇔ u = v. Pokud nelze přepsat obě strany na stejný základ, používáme logaritmování.

Typ úlohy Metoda Příklad
Stejný základ Porovnat exponenty 32x-1 = 35
Různé základy, ale převoditelné Přepsat na společný základ 9x = 3x+2
Kvadratický tvar v ax Substituce t = ax, t > 0 52x - 6·5x + 5 = 0
Nepřevoditelný tvar Logaritmování obou stran 2x = 7

Strategie řešení

  1. Zkontrolujte definiční podmínky. Exponenciální výraz je vždy kladný, tedy rovnice af(x) = c nemá řešení pro c ≤ 0.
  2. Pokuste se sjednotit základ. Přepis typu 9 = 32 často okamžitě zjednoduší rovnici.
  3. Je-li potřeba, použijte substituci. U tvarů a2x + pax + q = 0 položte t = ax a nezapomeňte na podmínku t > 0.
  4. Pokud nelze jinak, logaritmujte. Například ax = b vede na x = ln b / ln a, pokud b > 0.

Ukázkové příklady

Příklad A: stejný základ

2x+1 = 32

32 = 25
2x+1 = 25 ⇒ x + 1 = 5
x = 4

Příklad B: převod základu

9x = 3x+2

9x = (32)x = 32x
32x = 3x+2 ⇒ 2x = x + 2
x = 2

Příklad C: substituce

52x - 6·5x + 5 = 0

t = 5x, t > 0
t2 - 6t + 5 = 0 ⇒ (t - 1)(t - 5) = 0
t = 1 nebo t = 5
x = 0 nebo x = 1

Příklad D: logaritmování

2x = 7

ln(2x) = ln 7
x ln 2 = ln 7
x = ln 7 / ln 2 ≈ 2,807

Téma 2

Logaritmické rovnice

Logaritmické rovnice obsahují neznámou v argumentu logaritmu, například log₂(x - 1) = 5. Nejdůležitější je správně hlídat podmínky: základ a > 0, a ≠ 1 a argument každého logaritmu kladný.

Definiční podmínky

logₐ(u) je definován právě tehdy, když a > 0, a ≠ 1 a u > 0

U rovnic s více logaritmy je nutné splnit kladnost každého argumentu. Mnoho formálně získaných kořenů odpadne právě při kontrole podmínek.

Typ úlohy Metoda Poznámka
logₐ f(x) = logₐ g(x) Položit f(x) = g(x) Navíc musí platit f(x) > 0, g(x) > 0
Součet logaritmů logₐ u + logₐ v = logₐ(uv) Jen když u > 0, v > 0
logₐ f(x) = c Převod na exponenciální tvar f(x) = a^c Poté vyřešit běžnou rovnici v x
Smíšený tvar Nejprve upravit logaritmy, potom řešit Na konci vždy zkouška v původní rovnici

Ukázkové příklady

Příklad A: základní převod

log₂(x - 1) = 3

Podmínka: x - 1 > 0 ⇒ x > 1
x - 1 = 23 = 8
x = 9

Příklad B: součet logaritmů

log₃(x + 1) + log₃(x - 2) = 2

Podmínky: x > 2
log₃((x + 1)(x - 2)) = 2
(x + 1)(x - 2) = 9 ⇒ x2 - x - 11 = 0
x = (1 + 3√5) / 2 ≈ 3,854

Příklad C: dvě řešení

log₅(x2 - 4) = 1

x2 - 4 = 5
x2 = 9 ⇒ x = ±3
Kontrola podmínky: x2 - 4 > 0 platí pro obě hodnoty.
K = {−3, 3}

Příklad D: rovnost logaritmů

ln(x - 1) = ln(2x - 5)

Podmínky: x - 1 > 0 a 2x - 5 > 0 ⇒ x > 2,5
x - 1 = 2x - 5 ⇒ x = 4
x = 4 (vyhovuje podmínkám)

Téma 1

Kvadratické rovnice

Kvadratická rovnice je rovnice druhého stupně v jedné neznámé. Po úpravě má tvar ax² + bx + c = 0 s podmínkou a ≠ 0. V této části projdeme přesný postup řešení, interpretaci diskriminantu i kontrolu výsledků.

i

Kdy je rovnice kvadratická?

Rozhoduje nejvyšší mocnina neznámé po úpravě na nulový tvar. Jakmile je nejvyšší mocnina x² a její koeficient je nenulový, jde o kvadratickou rovnici.

Základní tvar a vzorec

ax² + bx + c = 0, a ≠ 0
x = (−b ± √(b² − 4ac)) / (2a)

Výraz D = b² − 4ac nazýváme diskriminant. Jeho znaménko určuje počet reálných kořenů.

Hodnota diskriminantu Počet reálných kořenů Tvar řešení
D > 0 Dva různé x₁, x₂ ∈ ℝ
D = 0 Jeden dvojnásobný x = −b / (2a)
D < 0 Žádný reálný V reálných číslech bez řešení

Postup řešení

  1. Upravte rovnici na tvar ax² + bx + c = 0. Zkontrolujte podmínku a ≠ 0.
  2. Spočítejte diskriminant D = b² − 4ac. Už zde víte, kolik reálných kořenů čekat.
  3. Dosadíte do vzorce pro kořeny. Při D = 0 vyjde jeden dvojnásobný kořen.
  4. Proveďte zkoušku dosazením. Ověříte tím, že kořeny skutečně nulují levou stranu.

Ukázkové příklady

Příklad A

Řešte: x² − 5x + 6 = 0

D = 25 − 24 = 1
x = (5 ± 1) / 2
K = {2, 3}

Příklad B

Řešte: 2x² + 3x − 2 = 0

D = 9 + 16 = 25
x = (−3 ± 5) / 4
K = {−2, 1/2}

Příklad C

Řešte: 3x² − 12x + 12 = 0

D = 144 − 144 = 0
x = 12 / 6 = 2
K = {2} (dvojnásobný kořen)

Téma 2

Odvození vzorce pro diskriminant

Vzorec pro kořeny kvadratické rovnice nevzniká „z ničeho“. Jde o přímý důsledek doplnění na čtverec. Tímto postupem se přirozeně objeví člen b² − 4ac, tedy diskriminant.

Odvození krok po kroku (obecně)

ax² + bx + c = 0
x² + (b/a)x + (c/a) = 0
x² + (b/a)x = −c/a
x² + (b/a)x + (b/2a)² = −c/a + (b/2a)²
(x + b/2a)² = (b² − 4ac) / (4a²)
x = (−b ± √(b² − 4ac)) / (2a)
i

Proč je diskriminant důležitý?

Diskriminant je výraz pod odmocninou. Pokud je záporný, v reálných číslech odmocninu nelze vyčíslit a rovnice nemá reálné řešení. Pokud je nulový, odmocnina je nulová a oba kořeny splývají.

Téma 3

Kvadratické rovnice s absolutní hodnotou

U rovnic s absolutní hodnotou nejprve analyzujeme pravou stranu a pak rozkládáme úlohu na případy. Pro tvar |Q(x)| = k s kvadratickým výrazem Q(x) se řešení převede na dvojici rovnic Q(x) = k a Q(x) = −k.

Tvar |Q(x)| = k

k < 0 ⇒ žádné řešení.

k = 0 ⇒ řešíme Q(x) = 0.

k > 0 ⇒ řešíme dvě rovnice: Q(x) = k a Q(x) = −k.

Tvar |Q(x)| = L(x)

Nejprve vyžadujeme podmínku L(x) ≥ 0.

Pak řešíme soustavu případů Q(x) = L(x) a Q(x) = −L(x).

Všechny kandidáty nakonec vždy ověřte v původní rovnici.

Ukázkové příklady

Příklad A

Řešte: |x² − 5x + 6| = 2

x² − 5x + 4 = 0 ⇒ x = 1, 4
x² − 5x + 8 = 0 ⇒ D = −7
K = {1, 4}

Příklad B

Řešte: |x² − 4x + 3| = 3

x² − 4x = 0 ⇒ x = 0, 4
x² − 4x + 6 = 0 ⇒ D = −8
K = {0, 4}

Příklad C

Řešte: |2x² + 2x + 5| = 1

2x² + 2x + 5 = 2(x + 1/2)² + 9/2 ≥ 9/2
Levá strana je vždy alespoň 9/2.
Rovnice nemá řešení.

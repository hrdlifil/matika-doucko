Téma 1

Úvod do rovnic vyšších mocnin

Rovnice vyšších mocnin jsou rovnice, kde je nejvyšší mocnina neznámé alespoň třetí, například x³ - 4x² + x - 6 = 0. Neexistuje jeden univerzální „vzorec na všechno“, proto se učíme sadu metod, které vybíráme podle tvaru rovnice.

i

Co je důležité vědět hned na začátku

Polynom stupně n má v komplexních číslech přesně n kořenů včetně násobností. V reálných číslech může být kořenů méně, ale nikdy více než n.

Situace Doporučený postup Typický tvar
Všechny členy mají společný faktor Vytknout a rozložit x⁴ - 5x³ + 4x² = 0
Polynom má „hezké“ celočíselné kořeny Uhádnout kořen + rozklad x³ - 6x² + 11x - 6 = 0
Chceme rychle dělit polynom výrazem x - r Hornerovo schéma P(x):(x - 2)
Rovnice má opakující se mocniny Substituce x⁴ - 5x² + 4 = 0

Strategie řešení

  1. Upravte rovnici na tvar P(x) = 0. Sečtěte podobné členy a zkontrolujte stupeň polynomu.
  2. Vyberte metodu podle struktury. Nezačínejte naslepo: tvar rovnice obvykle napoví nejlepší postup.
  3. Po získání kandidátů proveďte zkoušku. Dosazení do původní rovnice odhalí chyby i případné cizí kořeny.

Ukázkové příklady

Příklad A

Určete stupeň rovnice: 2x⁵ - 3x² + 1 = 0

Nejvyšší mocnina neznámé je x⁵.
Rovnice je polynomická rovnice pátého stupně.
Stupeň: 5

Příklad B

Posuďte: x³ - 3x + 2 = 0

Jde o kubickou rovnici.
V reálných číslech může mít 1, 2 nebo 3 různé kořeny.
Maximálně 3 reálné kořeny

Příklad C

Určete vhodnou metodu pro x⁶ - 7x³ + 6 = 0.

Vyskytují se jen mocniny x⁶ a x³.
Je vhodná substituce t = x³.
Použijeme substituční metodu

Téma 2

Metoda vytýkání

Vytýkání je první metoda, kterou je vhodné zkusit téměř vždy. Pokud mají všechny členy společný faktor (číslo nebo mocninu x), rovnici výrazně zjednodušíme a často ji převedeme na součinový tvar.

Princip

A·B = 0 ⇔ A = 0 nebo B = 0

Po vytknutí získáme součin. Každý činitel položíme rovný nule a vyřešíme samostatně.

Ukázkové příklady

Příklad A

x⁴ - 5x³ + 4x² = 0

x²(x² - 5x + 4) = 0
x²(x - 1)(x - 4) = 0
K = {0, 1, 4} (x = 0 je dvojnásobný kořen)

Příklad B

2x⁵ - 18x³ = 0

2x³(x² - 9) = 0
2x³(x - 3)(x + 3) = 0
K = {−3, 0, 3} (x = 0 je trojnásobný kořen)

Příklad C

−3x⁶ + 12x⁴ − 9x² = 0

−3x²(x⁴ − 4x² + 3) = 0
−3x²(x² − 1)(x² − 3) = 0
V ℝ: K = {0, ±1, ±√3}

Téma 3

Metoda uhádnutí kořene

Pokud má polynom celočíselné nebo racionální kořeny, můžeme je často odhadnout z kandidátů daných větou o racionálních kořenech. Po nalezení jednoho kořene rovnici snížíme na nižší stupeň.

Věta o racionálních kořenech (prakticky)

Pro rovnici s celočíselnými koeficienty aₙxⁿ + ... + a₀ = 0 může mít racionální kořen tvar p/q, kde p dělí absolutní člen a₀ a q dělí vedoucí koeficient aₙ.

Ukázkové příklady

Příklad A

x³ - 6x² + 11x - 6 = 0

Kandidáti: ±1, ±2, ±3, ±6
P(1) = 0, pak (x - 1) je činitel.
(x - 1)(x - 2)(x - 3) = 0
K = {1, 2, 3}

Příklad B

2x³ - 3x² - 8x + 12 = 0

P(2) = 0 ⇒ dělíme výrazem (x - 2).
Zbytek: 2x² + x - 6
2x² + x - 6 = (2x - 3)(x + 2)
K = {−2, 3/2, 2}

Příklad C

x⁴ + x³ - 7x² - x + 6 = 0

P(1) = 0, po dělení dostaneme x³ + 2x² - 5x - 6.
P(2) = 0, zbude x² + 4x + 3.
x² + 4x + 3 = (x + 1)(x + 3)
K = {−3, −1, 1, 2}

Interaktivní trenažer: kandidáti a test kořene

Zkuste odhadnout kořen vybraného polynomu. Počítá se dosazení P(r) a hned uvidíte, jestli jste trefili.

Zadání

x³ - 6x² + 11x - 6 = 0
Kandidáti (racionální): ±1, ±2, ±3, ±6

Vyhodnocení

Zatím nevyhodnoceno.

Tip: pokud P(r) = 0, je r kořen.

Téma 4

Řešení pomocí Hornerova schématu

Hornerovo schéma je rychlý a přehledný způsob dělení polynomu výrazem x - r. Pokud vyjde zbytek nula, je r kořen a x - r činitel polynomu.

Klíčová vazba

P(r) = zbytek po dělení P(x) výrazem (x − r)

Tato věta spojuje dosazení a dělení polynomu. V praxi výrazně zrychluje hledání kořenů.

Ukázkové příklady

Příklad A

x³ - 6x² + 11x - 6, test r = 1

Koeficienty: 1, -6, 11, -6
Horner: 1 | 1, -5, 6, 0
Kvocient: x² - 5x + 6, zbytek 0
1 je kořen

Příklad B

x⁴ - 3x³ - 7x² + 27x - 18 = 0

Horner pro r = 1 ⇒ zbytek 0
Pokračujeme s r = 2 ⇒ zbytek 0
Zbude x² - 9 = 0
K = {−3, 1, 2, 3}

Příklad C

Určete zbytek po dělení x³ + 2x² - 5x - 6 výrazem x - 1

Stačí spočítat P(1).
P(1) = 1 + 2 - 5 - 6 = -8
Zbytek je −8

Téma 5

Substituční metoda

Substituce převádí rovnici vyššího stupně na jednodušší rovnici v nové proměnné. Nejčastěji nahrazujeme opakující se mocniny, například t = x² nebo t = x³.

Bikvadratický tvar

Pro rovnici x⁴ + ax² + b = 0 položíme t = x² (a tedy t ≥ 0).

Řešíme kvadratickou rovnici t² + at + b = 0 a zpětně dopočteme x.

Mocniny násobku

Pro tvar x⁶ + px³ + q = 0 volíme t = x³.

Po vyřešení rovnice v t řešíme x³ = t.

Ukázkové příklady

Příklad A

x⁴ - 5x² + 4 = 0

t = x² ⇒ t² - 5t + 4 = 0
t₁ = 1, t₂ = 4
x² = 1 nebo x² = 4
K = {−2, −1, 1, 2}

Příklad B

x⁶ - 7x³ + 6 = 0

t = x³ ⇒ t² - 7t + 6 = 0
t = 1 nebo t = 6
V reálných číslech: x = 1 nebo x = ∛6
V ℝ: K = {1, ∛6}

Příklad C

x⁴ + 4x² + 4 = 0

t = x² ⇒ t² + 4t + 4 = 0
(t + 2)² = 0 ⇒ t = -2
x² = -2 nemá v reálných číslech řešení.
V ℝ: rovnice nemá řešení

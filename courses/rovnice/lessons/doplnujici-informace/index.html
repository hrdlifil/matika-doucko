Téma 1

Rovnice jako funkce a grafické řešení

Každou rovnici tvaru f(x) = g(x) můžeme číst jako porovnání dvou funkcí. Řešení rovnice jsou právě ty hodnoty x, pro které mají obě funkce stejnou hodnotu, tedy kde se jejich grafy protínají.

i

Základní princip

Hledat řešení rovnice f(x) = g(x) znamená hledat x-ové souřadnice průsečíků grafů y = f(x) a y = g(x).

Převod do standardního tvaru

Rovnici často převedeme na tvar

f(x) - g(x) = 0

a řešíme kořeny funkce h(x) = f(x) - g(x). Graficky to znamená průsečíky s osou x.

Doporučený postup

  1. Určete definiční obor. Musí být definované obě strany rovnice.
  2. Nakreslete oba grafy nebo použijte tabulku hodnot. Při ručním náčrtu hlídejte měřítko os.
  3. Odečtěte průsečíky. Grafické řešení je zpravidla pouze přibližné.
  4. Výsledek ověřte algebraicky. Dosazením předejdete chybnému odečtu z grafu.

Ukázkové příklady

Příklad A

Řešte rovnici: 2x + 1 = x2 - 3

x2 - 2x - 4 = 0
x = 1 ± √5
x1 ≈ -1,236; x2 ≈ 3,236

Graf přímky y = 2x + 1 a paraboly y = x2 - 3 má dva průsečíky, proto dvě řešení.

Příklad B

Řešte rovnici: |x - 2| = x/2

Podmínka z pravé strany: x ≥ 0
x ≥ 2: x - 2 = x/2 ⇒ x = 4
0 ≤ x < 2: 2 - x = x/2 ⇒ x = 4/3
K = {4/3, 4}

Graf absolutní hodnoty ("V" tvar) a přímky se protíná ve dvou bodech.

Příklad C

Řešte rovnici: 1/(x - 1) = x - 2

Podmínka: x ≠ 1
1 = (x - 1)(x - 2)
x2 - 3x + 1 = 0
x = (3 ± √5)/2 ≈ 0,382; 2,618

U lomených rovnic je nutné nejdřív zapsat podmínky na jmenovatel.

Pozor: grafické řešení může "přehlédnout" řešení, pokud je nevhodné měřítko, průsečík je velmi blízko, nebo funkce jen "líže" osu.

Téma 2

Rovnice s parametrem

V rovnici s parametrem vystupuje kromě neznámé (např. x) ještě parametr (např. m, a, k). Parametr považujeme za známé číslo a zkoumáme, jak změna jeho hodnoty mění počet a tvar řešení.

Klíčový krok u lineární rovnice

Pro rovnici tvaru

A(p)x = B(p)

rozhoduje, zda A(p) je nulové nebo nenulové.

Situace Důsledek Počet řešení
A(p) ≠ 0 x = B(p)/A(p) Právě jedno
A(p) = 0 a B(p) = 0 identita 0 = 0 Nekonečně mnoho
A(p) = 0 a B(p) ≠ 0 spor 0 = c Žádné

Ukázkové příklady

Příklad A: případ s nekonečně mnoha řešeními

(m - 2)x = m2 - 4

m ≠ 2 ⇒ x = (m2 - 4)/(m - 2) = m + 2
m = 2 ⇒ 0x = 0
pro m = 2 má rovnice nekonečně mnoho řešení

Příklad B: případ bez řešení

(m - 2)x = m + 1

m ≠ 2 ⇒ x = (m + 1)/(m - 2)
m = 2 ⇒ 0x = 3
pro m = 2 rovnice nemá řešení

Kvadratická rovnice s parametrem

Vyšetřete počet reálných řešení rovnice

x2 - 2(a + 1)x + a2 - 1 = 0
D(a) = [−2(a + 1)]2 − 4(a2 − 1)
D(a) = 4(a + 1)2 − 4a2 + 4 = 8(a + 1)
a > −1 ⇒ D > 0 ⇒ dvě různá reálná řešení
a = −1 ⇒ D = 0 ⇒ jedno dvojnásobné řešení
a < −1 ⇒ D < 0 ⇒ žádné reálné řešení
Důležité: u kvadratické rovnice s parametrem vždy nejdřív ověřte, že koeficient u x2 není nula. Jinak se rovnice může zredukovat na lineární.

Téma 3

Vyjádření neznámé ze vzorce

Vyjádřit neznámou ze vzorce znamená algebraicky upravit rovnici tak, aby zvolená proměnná byla sama na jedné straně rovnosti. Jde o stejný princip jako u řešení rovnic, jen ostatní symboly považujeme za známé konstanty.

Univerzální postup

  1. Určete, co izolujete. Např. vyjádřit t ze vzorce pro pohyb.
  2. Proveďte ekvivalentní úpravy. Sčítání, odčítání, násobení, dělení stejným nenulovým výrazem.
  3. Zapište podmínky. Co nesmí být nula ve jmenovateli, co musí být nezáporné pod odmocninou.
  4. Zkontrolujte smysl výsledku. Jednotky a fyzikální omezení (např. délka, čas nebo poloměr nejsou záporné).

Ukázkové příklady

Příklad A: kinematika

v = v0 + at, vyjádři t.

v - v0 = at
t = (v - v0) / a, a ≠ 0

Příklad B: obsah trojúhelníku

S = (a va) / 2, vyjádři va.

2S = a va
va = 2S / a, a ≠ 0

Příklad C: paralelní rezistory

R = (R1R2) / (R1 + R2), vyjádři R2.

R(R1 + R2) = R1R2
RR1 = R2(R1 - R)
R2 = RR1 / (R1 - R), R1 ≠ R

Příklad D: poloměr z obsahu kruhu

A = πr2, vyjádři r.

r2 = A / π
r = √(A / π), r ≥ 0
Častá chyba: po úpravě zapomenutá podmínka. Například pokud dělíte výrazem a, musíte uvést a ≠ 0.

Téma 1

Lineární rovnice

Lineární rovnice s jednou neznámou má po úpravě tvar ax + b = 0. Cílem je najít všechna x, pro která je rovnost pravdivá.

i

Klíčová myšlenka

U lineární rovnice rozhoduje hlavně koeficient u x. Pokud je nenulový, řešení je právě jedno. Pokud je nulový, může být řešení žádné nebo nekonečně mnoho.

Obecný tvar

ax + b = 0, kde a, b ∈ ℝ
Podmínka Výsledek Počet řešení
a ≠ 0 x = −b/a Právě jedno
a = 0, b = 0 identita 0 = 0 Nekonečně mnoho
a = 0, b ≠ 0 spor b = 0 Žádné

Postup řešení krok za krokem

  1. Rozevřete závorky a odstraňte zlomky. Rovnici převeďte do přehledného tvaru.
  2. Sečtěte členy s neznámou a konstanty. Cílem je tvar Ax = B.
  3. Vydělte koeficientem u neznámé. Pokud A ≠ 0, dostanete jedno řešení.
  4. Proveďte zkoušku. Dosazením ověříte, že výsledek skutečně platí.

Ukázkové příklady

Příklad A

Řešte rovnici: 7x - 9 = 2x + 11

7x - 2x = 11 + 9
5x = 20
x = 4

Příklad B

Řešte rovnici: 3(2x - 5) - 4 = 2(x + 7)

6x - 15 - 4 = 2x + 14
6x - 19 = 2x + 14
4x = 33
x = 33/4 = 8,25

Příklad C

Řešte rovnici: (5 - 2x)/3 - (x + 1)/2 = 4

2(5 - 2x) - 3(x + 1) = 24
10 - 4x - 3x - 3 = 24
7 - 7x = 24
−7x = 17
x = −17/7
Častá chyba: přenášení členů bez změny znaménka. Například při přechodu z 7x - 9 = 2x + 11 na 7x - 2x = 11 + 9 se znaménka mění správně.

Téma 2

Lineární rovnice s absolutní hodnotou

Absolutní hodnota mění rovnici na úlohu s případy. Zápis |u(x)| vyjadřuje vzdálenost od nuly, proto je vždy nezáporný.

Základní pravidla

|u| = u, pokud u ≥ 0
|u| = −u, pokud u < 0

Tvar |A(x)| = k

k < 0 ⇒ žádné řešení.

k = 0 ⇒ A(x) = 0.

k > 0 ⇒ A(x) = k nebo A(x) = −k.

Tvar |A(x)| = B(x)

Nejprve musí platit B(x) ≥ 0.

Pak řešíme případy A(x) = B(x) a A(x) = −B(x).

Každý výsledek ověřte v původní rovnici.

Ukázkové příklady

Příklad A

Řešte rovnici: |2x - 5| = 7

2x - 5 = 7 nebo 2x - 5 = −7
x = 6 nebo x = −1
K = {−1, 6}

Příklad B

Řešte rovnici: |3x + 1| = 2x + 5

Podmínka: 2x + 5 ≥ 0 ⇒ x ≥ −2,5
1) 3x + 1 = 2x + 5 ⇒ x = 4
2) −(3x + 1) = 2x + 5 ⇒ −5x = 6 ⇒ x = −6/5
K = {−6/5, 4}

Příklad C

Řešte rovnici: |3x - 6| = −2

|3x - 6| je vždy ≥ 0
Pravá strana je záporná.
Rovnice nemá řešení.
Důležité: po rozdělení na případy vždy kontrolujte podmínky (například B(x) ≥ 0) a proveďte zkoušku dosazením.

Téma 3

Grafické řešení lineárních rovnic

Rovnici ax + b = cx + d lze řešit i graficky: hledáme průsečík přímek y = ax + b a y = cx + d.

+

Vztah ke klasickému řešení

Souřadnice průsečíku mají tvar (x, y). Hodnota x je právě řešení původní rovnice.

Vzorec pro průsečík (pokud přímky nejsou rovnoběžné)

x = (d − b)/(a − c), kde a ≠ c
Situace Geometrický význam Počet řešení rovnice
a ≠ c Přímky se protínají v jednom bodě. Právě jedno řešení
a = c, b ≠ d Rovnoběžné různé přímky Žádné řešení
a = c, b = d Splývající přímky Nekonečně mnoho řešení

Ukázkové příklady

Příklad A

Řešte rovnici: 2x + 1 = −x + 7

3x = 6
x = 2
y = 2·2 + 1 = 5
Průsečík je (2, 5), řešení je x = 2.

Příklad B

Řešte rovnici: 3x − 4 = 3x + 2

Po odečtení 3x dostaneme −4 = 2.
Směrnice jsou stejné, absolutní členy jiné.
Přímky jsou rovnoběžné, řešení neexistuje.

Příklad C

Řešte rovnici: 5 − 2x = 5 − 2x

Obě strany jsou shodné pro každé x.
Graficky jde o jednu a tutéž přímku.
Rovnice má nekonečně mnoho řešení.
Pozor: grafické řešení je při ručním náčrtu pouze přibližné. Přesnou hodnotu vždy dopočítejte algebraicky.

Téma 4

Lineární rovnice s parametrem

V rovnici s parametrem hledáme řešení pro neznámou x podle hodnoty parametru p, m nebo k.

Nejčastější tvar

A(p)x = B(p)
Podmínka Důsledek Počet řešení
A(p) ≠ 0 x = B(p)/A(p) Právě jedno
A(p) = 0 a B(p) = 0 identita 0 = 0 Nekonečně mnoho
A(p) = 0 a B(p) ≠ 0 spor 0 = c Žádné

Ukázkové příklady

Příklad A

(m - 1)x = 2m - 2

m ≠ 1 ⇒ x = (2m − 2)/(m − 1) = 2
m = 1 ⇒ 0x = 0
Pro m = 1 má rovnice nekonečně mnoho řešení.

Příklad B

(k + 3)x = k − 1

k ≠ −3 ⇒ x = (k − 1)/(k + 3)
k = −3 ⇒ 0x = −4
Pro k = −3 rovnice nemá řešení.

Příklad C

(a² − 4)x = a + 2

a ≠ ±2 ⇒ x = (a + 2)/(a² − 4) = 1/(a − 2)
a = 2 ⇒ 0x = 4 (bez řešení)
a = −2 ⇒ 0x = 0 (nekonečně mnoho řešení)
Je nutné vždy oddělit nulové hodnoty koeficientu.
Důležité: nepoužívejte mechanicky dělení výrazem s parametrem. Nejprve vyšetřete, kdy může být tento výraz nulový.

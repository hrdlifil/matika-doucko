Přímka v rovině

Přímka je jedním z nejzákladnějších geometrických útvarů. V analytické geometrii můžeme přímku popsat několika způsoby pomocí rovnic. Každý způsob má své výhody a je vhodný pro různé situace.

💡

Co se naučíte

  • Parametrické vyjádření přímky
  • Obecnou rovnici přímky
  • Směrnicový tvar přímky
  • Převody mezi jednotlivými tvary

Tři způsoby zápisu přímky

Parametrické vyjádření

x = x₀ + t·a
y = y₀ + t·b

Bod [x₀, y₀] a směrový vektor (a, b)

Obecná rovnice

ax + by + c = 0

Koeficienty a, b určují normálový vektor

Směrnicový tvar

y = kx + q

k je směrnice, q je úsek na ose y

Parametrické vyjádření

Parametrické vyjádření přímky

Přímka je jednoznačně určena bodem, kterým prochází, a směrovým vektorem, který udává její směr.

Definice

Nechť A = [x₀, y₀] je bod přímky p a s = (a, b) je její směrový vektor. Pak parametrické vyjádření přímky p je:

x = x₀ + t·a
y = y₀ + t·b

kde t ∈ ℝ je parametr.

🎮 Interaktivní ukázka

Pohybujte posuvníky a sledujte, jak se mění přímka:

Parametrické rovnice:
x = 2 + t·3
y = 1 + t·2
Obecná rovnice

Obecná rovnice přímky

Obecná rovnice přímky je algebraický zápis, který využívá normálový vektor – vektor kolmý na přímku.

Definice

Obecná rovnice přímky má tvar:

ax + by + c = 0

kde n = (a, b) je normálový vektor přímky (vektor kolmý na přímku).

⚠️

Důležité

Normálový vektor n = (a, b) je kolmý ke směrovému vektoru s. Pokud s = (s₁, s₂), pak n = (s₂, -s₁) nebo n = (-s₂, s₁).

🎮 Interaktivní ukázka

Měňte koeficienty a, b, c a sledujte změnu přímky:

Obecná rovnice:
2x + 3y - 6 = 0
Normálový vektor: n = (2, 3)
Směrnicový tvar

Směrnicový tvar přímky

Směrnicový tvar je nejintuitivnější způsob zápisu přímky. Přímo ukazuje sklon přímky a kde protíná osu y.

Definice

Směrnicový tvar přímky je:

y = kx + q

kde k je směrnice (sklon přímky) a q je úsek na ose y (y-intercept).

Co je směrnice k?

  • k > 0: přímka stoupá
  • k < 0: přímka klesá
  • k = 0: vodorovná přímka
  • k = 1: úhel 45°
  • k = tan(α), kde α je úhel s osou x

Co je q?

  • Bod [0, q] leží na přímce
  • Je to průsečík s osou y
  • q > 0: nad počátkem
  • q < 0: pod počátkem

🎮 Interaktivní ukázka

Experimentujte se směrnicí k a úsekem q:

Směrnicový tvar:
y = 1x + 2
Úhel s osou x: 45°

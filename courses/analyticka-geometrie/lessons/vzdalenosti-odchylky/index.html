Vzdálenosti a odchylky

V této kapitole se naučíte měřit vzdálenost bodu od přímky, vzdálenost mezi dvěma rovnoběžnými přímkami a úhel (odchylku) dvou přímek. Tyto výpočty jsou klíčové pro mnoho praktických úloh v analytické geometrii.

💡

Co se naučíte

  • Vzorec pro vzdálenost bodu od přímky
  • Vzdálenost dvou rovnoběžných přímek
  • Odchylku (úhel) dvou přímek
  • Praktické aplikace těchto vzorců

Předpoklady

Pro tuto kapitolu budete potřebovat znalost obecné rovnice přímky ve tvaru ax + by + c = 0 a základy práce s normálovým a směrovým vektorem.

📐

Obecná rovnice přímky

Přímka p: ax + by + c = 0, kde n = (a, b) je normálový vektor.

Vzdálenost bodu od přímky

Vzdálenost bodu od přímky

Vzdálenost bodu od přímky je délka kolmice spuštěné z bodu na přímku — tedy nejkratší možná vzdálenost.

Vzorec

Je-li přímka p: ax + by + c = 0 a bod M = [m₁, m₂], pak vzdálenost bodu M od přímky p je:

d(M, p) = |a·m₁ + b·m₂ + c| / √(a² + b²)

V čitateli je absolutní hodnota dosazení bodu do rovnice přímky. Ve jmenovateli je velikost normálového vektoru.

📝

Příklad

Přímka p: 3x + 4y − 2 = 0, bod M = [1, 3]:

d = |3·1 + 4·3 − 2| / √(9 + 16) = |3 + 12 − 2| / √25 = 13 / 5 = 2.6

⚠️

Pozor!

Nezapomeňte na absolutní hodnotu v čitateli! Vzdálenost je vždy nezáporné číslo. Bez absolutní hodnoty bychom mohli dostat záporný výsledek, což by znamenalo, že jsme se spletli.

Vzdálenost rovnoběžek

Vzdálenost rovnoběžných přímek

Dvě rovnoběžné přímky mají stejný normálový vektor (popř. násobky). Jejich vzdálenost je konstantní a lze ji snadno vypočítat.

Vzorec

Pro dvě rovnoběžné přímky p: ax + by + c₁ = 0 a q: ax + by + c₂ = 0 platí:

d(p, q) = |c₁ − c₂| / √(a² + b²)

Přímky musí mít stejné koeficienty a, b (případně je normalizujeme).

💡

Alternativní postup

Vzdálenost rovnoběžek lze také spočítat tak, že na jedné přímce zvolíme libovolný bod a spočítáme jeho vzdálenost od druhé přímky.

🎮 Interaktivní ukázka

Upravte posuvníky a sledujte vzdálenost dvou rovnoběžných přímek:

📍 Rovnoběžné přímky

📐 Výpočet

📝

Příklad

Přímky p: 3x − 4y + 6 = 0 a q: 3x − 4y − 4 = 0:

d = |6 − (−4)| / √(9 + 16) = 10 / 5 = 2.0

Odchylka přímek

Odchylka dvou přímek

Odchylka (úhel) dvou přímek je ostrý úhel, který přímky svírají. Je vždy z intervalu ⟨0°, 90°⟩.

Vzorec pomocí normálových vektorů

Pro přímky p: a₁x + b₁y + c₁ = 0 a q: a₂x + b₂y + c₂ = 0 s normálovými vektory n₁ = (a₁, b₁) a n₂ = (a₂, b₂):

cos α = |a₁a₂ + b₁b₂| / (√(a₁² + b₁²) · √(a₂² + b₂²))

Absolutní hodnota v čitateli zajišťuje, že dostaneme ostrý úhel (0° až 90°).

Pomocí směrnic

Pokud známe směrnice k₁ a k₂ dvou přímek:

tg α = |k₁ − k₂| / |1 + k₁·k₂|

Platí pro k₁·k₂ ≠ −1.

Speciální případy

  • α = 0° — přímky jsou rovnoběžné
  • α = 90° — přímky jsou na sebe kolmé

Kolmé přímky: a₁a₂ + b₁b₂ = 0

Příklad

Přímky p: 2x − y + 1 = 0 a q: x + 3y − 5 = 0:

cos α = |2·1 + (−1)·3| / (√5 · √10) = |2 − 3| / √50 = 1/√50 ≈ 0.141

α ≈ 81.9°

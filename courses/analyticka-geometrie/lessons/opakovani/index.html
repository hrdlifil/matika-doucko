Přímka v rovině

Kap. 5–6 ▼
Obecná rovnice
ax + by + c = 0
Směrnicový tvar
y = kx + q,   k = −a/b
Parametrická rovnice
X = A + t · u,   t ∈ ℝ
Normálový vektor
n = (a, b) pro ax + by + c = 0
Odchylka dvou přímek
cos α = |u · v| / (|u| · |v|)

Kuželosečky

Kap. 7–10 ▼
Kružnice
(x−m)² + (y−n)² = r²
Elipsa
x²/a² + y²/b² = 1,   c² = a² − b²
Hyperbola
x²/a² − y²/b² = 1,   c² = a² + b²
Parabola
y² = 2px  (osa x),   x² = 2py  (osa y)
Excentricita
e = c/a  (elipsa: e<1, hyperbola: e>1)

Geometrie v prostoru

Vektorový součin
u × v = (u₂v₃−u₃v₂, u₃v₁−u₁v₃, u₁v₂−u₂v₁)
Rovnice roviny
ax + by + cz + d = 0
Vzdálenost bod–rovina
d = |ax₀+by₀+cz₀+d| / √(a²+b²+c²)
